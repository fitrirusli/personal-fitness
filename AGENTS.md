# Personal Fitness project instructions

The owner authorized implementation of a gym, nutrition, and lifestyle application for personal Android use. The goal is fat loss, muscle development, strength, and conditioning; body weight is not the main success metric.

- Use React JavaScript and JSX. Do not author TypeScript application code.
- Write documentation, source identifiers, and application text in English.
- Make the application useful offline. Android must use bundled assets and local persistence rather than depending on a laptop server.
- Keep Android source/projects, APK/AAB outputs, signing keys, local toolchains, credentials, and all personal records excluded from the web repository.
- The web source is public. Share Android APK builds only as assets in the separately authorized private repository. Keep signing keys, local toolchains, credentials, Android projects, and personal records local.
- Implement explainable, conservative recommendations. Treat missing nutrient values as unknown, not zero. Do not diagnose nutritional deficiencies or prescribe through pain.
- Use real food composition data with provenance and preserve nutrition snapshots when logging meals.
- Keep personal data local by default. Remote sync must be explicit and authenticated.
- Use fictional data only in the optional demonstration mode. Never confuse demonstration data with the owner's records.
- Preserve sibling projects and system-wide runtime configuration.
- Verify progression decisions, food aggregation, persistence, import validation, and important user journeys with meaningful tests.

Working name: Personal Fitness. This is descriptive and does not claim unique branding.
